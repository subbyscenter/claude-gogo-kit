# 옵시디언 보관함 쓰는 법 (사람용)

## 요약
이 보관함은 **Claude의 기억 노트**예요. Claude가 일하면서 알게 된 것(업무 방법, 결정, 실수, 거래처 정보 등)을 여기에 정리해 두고, 다음 대화에서 다시 꺼내 써요. 대화창을 닫아도 기억이 이어지는 이유가 이거예요.

## Claude에게 이렇게 말하면 돼요

| 이렇게 말하면 | Claude가 하는 일 |
|---|---|
| `/gogo` (대화 처음에) | 세팅 점검 + 지난번에 하던 일 불러오기 |
| "저장해줘" / "옵시디언에 남겨줘" | 지금 대화에서 다시 쓸 내용을 정리해서 저장 |
| "옵시디언 참조" / "이어서 하자" | 지난 맥락 요약 |
| "위키에서 ○○ 찾아줘" | 저장된 내용으로 답 (어느 문서에서 왔는지 같이) |
| (파일을 `AI-Sessions/raw`에 넣고) "이 자료 정리해줘" | 자료를 읽고 요약·사람·결정으로 나눠 정리 |
| "위키 점검해줘" | 겹치거나 틀린 내용, 빠진 링크를 찾아서 보고 (고치는 건 허락받고) |
| "카파시라면?" / "더 좋은 방법 있어?" | 지금 방법보다 나은 방법이 있는지 알아보고 하나 추천 |

## 옵시디언 앱에서 보기
- 왼쪽 파일 목록 → `index.md`(목차)부터 보면 돼요.
- 문서 안의 `[[이름]]`을 누르면 그 문서로 넘어가요.
- 왼쪽 메뉴의 **그래프 보기**(동그라미 연결 아이콘)를 누르면 문서끼리 어떻게 이어졌는지 그림으로 보여요.
- `Ctrl + O` = 문서 이름으로 찾기, `Ctrl + Shift + F` = 내용으로 찾기.

## 지켜 주세요
- `AI-Sessions/raw` = 원본 자료 넣는 곳 (Claude가 고치지 않아요). 자료는 여기에 넣으면 돼요.
- `AI-Sessions/wiki/guides` = **직접 써도 되는 곳**. "보고서는 이런 말투로", "○○ 거래처는 이것 주의" 같은 규칙을 적어 두면 Claude가 따라요.
- 나머지 `wiki` 문서는 Claude가 관리해요. 고쳐도 되지만, 고쳤다고 Claude에게 말해 주면 더 좋아요.
- 비밀번호·카드번호 같은 건 저장하지 마세요.
