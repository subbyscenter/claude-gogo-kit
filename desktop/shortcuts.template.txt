# 바로가기 목록 — Ctrl+Shift+F 창에 동그란 아이콘으로 떠요. 창 오른쪽 위 ＋ 버튼으로 넣는 게 제일 쉬워요.
# 직접 쓸 때: [카테고리] 줄 아래에 한 줄에 하나 — 이름 | 주소 | 아이콘(선택) | 브라우저 프로필(선택)
#   주소 = https://… 웹 주소, C:\… 폴더·파일, 또는 웹 주소 여러 개를 띄어 쓰기(그룹: 한꺼번에 열림)
#   아이콘 = 그림 파일(icons\사진.png) 또는 원 색(#3B82F6). 없으면 사이트 아이콘이나 이름 글자
# 예)  [회사]
#      메일 | https://mail.example.com
#      공유 폴더 | C:\Users\나\Documents\회사
