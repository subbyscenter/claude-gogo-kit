# /gogo — 점검 → 고치기 → 맥락 불러오기 → 시작

## 1. 점검 + 자동 수리

`{{GOGO}} check --fix` 를 실행한다 (고칠 수 있는 것은 스크립트가 고치고 다시 점검한 표를 출력).

이어서 스크립트가 못 보는 두 가지를 직접 확인해 표에 더한다:
- **스킬 로드**: 이번 세션의 사용 가능한 스킬 목록에 `gogo`, `karpathy` 가 있는가. 파일은 있는데 목록에 없으면 ⚠️ "새 세션 필요".
- **caveman 적용**: 이번 세션 시작 때 caveman 안내(SessionStart 훅)가 들어왔는가. 막 설치했다면 ⚠️ "새 세션부터".

## 2. 남은 문제

- ❌ 가 남으면 원인과 사용자가 할 일을 쉬운 말로 한 줄씩. 고칠 수 있으면 더 고치고 다시 `check`. (같은 수리를 두 번 넘게 반복하지 않는다.)
- 디스코드 토큰처럼 사용자만 할 수 있는 일은 "할 일"로 남기고, 나머지로 세션을 시작한다 (막지 않는다).

## 3. 맥락 불러오기 (옵시디언 reference)

보관함 `{{VAULT}}` 에서 읽기만 한다:
1. `index.md` (⭐ 즐겨찾기 먼저)
2. `log.md` 마지막 10줄
3. `AI-Sessions/wiki/projects/pc-map.md` (PC·폴더 지도) — 지금 작업 폴더가 지도에 없으면 한 줄 더할 것을 메모
4. 최근 `AI-Sessions/conversations/` 2개 (있으면)

## 4. 디스코드에서 못 받은 답

`{{ASK}} answers --from "<세션 이름>"` (봇 토큰이 없으면 건너뜀). 답이 있으면 요약에 넣는다.
