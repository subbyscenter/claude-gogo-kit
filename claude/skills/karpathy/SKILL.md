# 카파시라면? — 더 나은 방법 연구·추천

"카파시라면?" = "지금 방향이 최선이 아닐 수 있으니, 최고 수준 전문가라면 어떻게 했을지 알아보고 더 나은 길을 추천해줘"의 줄임말이다. 하려던 방향을 **그대로 밀지 말고** 한 번 멈춰 연구한다.

## 순서

1. **지금 방향 한 줄로**: 사용자가 하려는 것(또는 방금 내가 제안한 것)을 1~2줄로 적어, 무엇을 평가하는지부터 맞춘다.
2. **표준·대안 찾기**: 이 문제의 업계 표준 + 최고 수준 전문가들의 방식 2~3개. 최신 사실·도구·가격·규정은 **추측 금지** — 웹 검색 등으로 확인한다.
3. **비교표**: 사용자 방식 vs 대안 — 정확성·단순함·나중에 늘리기 쉬움·비용·되돌리기 쉬움.
4. **추천 1개 + 이유**: 셋 중 하나로 분명하게 — **그대로 OK / 이렇게 고치기 / 표준 방식으로 바꾸기**.
5. **카파시 렌즈**(감이 아니라 확인할 수 있게): ① 무엇으로 잘됐는지 잴지 먼저 정하기 ② 단순하게 ③ 제일 막히는 곳부터 ④ 자동화·다시 해도 같은 결과 ⑤ 더 적은 일로 같은 결과.

## 분량 = 결정의 무게

- 되돌리기 어렵거나 여러 일에 퍼지는 결정 → 대안 3개까지 꼼꼼히.
- 사소하거나 한 번만 할 일 → 한 줄 비교나 "이게 표준이에요" 한 줄로 끝. 길게 끌지 않는다.
- 사용자가 "그냥 해" / "비교 생략"이라고 하면 그 대화에선 끈다.

## 결과

표준과 비교한 내 판단 + **추천 하나** + 근거. 다시 쓸 만한 교훈은 옵시디언 보관함(`{{VAULT}}`)에 저장한다 (Save Filter 통과분만).
